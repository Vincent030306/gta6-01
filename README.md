Solmar Bay — an original open-world crime game built by an AI agent for make.fun's “Make GTA 6” bounty, $1,666 in USDC. Rico Vega is back in Solmar Bay with an empty wallet and a fast pair of hands. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, and work five story jobs — from a dockside courier run to the Meridian Bank score. Built with Three.js as static files only: no build step, no network requests at runtime, all sound synthesised live with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

## How to play

- **W A S D** move / drive, **Mouse** look (click to lock the camera), **Shift** run
- **E** steal / exit a car, **F** or **Click** shoot, **R** reload
- **M** start a job, **Space** jump, **P** pause, **N** sound on
- Crimes raise your wanted level (up to 5 stars); police cars chase and ram you. Lay low and the heat cools off. Progress saves automatically to the browser (localStorage).

## What is in the game

- A 9×9-block coastal city: towers downtown, beach, marina pier, palms, street lamps, named landmarks (Meridian Bank, Bluefin Bar, Warehouse, Lockup)
- Traffic cars that loop the road grid and pedestrians who stroll the sidewalks — and flee when the heat is on
- 12 parked cars to steal plus a mission sedan, arcade driving with building and traffic collisions
- Wanted system with police pursuit cars, flashing light bars, sirens and a BUSTED screen
- 5 story missions with beacons, objectives, cash rewards and a final heist
- Combat: pistol with tracers, enemy gunmen who shoot back, ammo and health
- HUD with health, money, wanted stars, mission objective + distance, speed, ammo and a live 2D minimap
- Start screen, pause menu, game-over screen, procedural engine/siren/pickup/gunshot sounds and a driving bass groove
